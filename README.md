# 달려라 백호돌이 🐯

KSPO(국민체육진흥공단)의 경영가치를 재미있게 체험·각인시키는 웹 엔드리스 러너 미니게임입니다.
크롬 공룡 게임(T-Rex Runner) 방식을 기반으로, 백호돌이가 **핵심가치에 반하는 장애물(극복 대상)**을 뛰어넘으며
3개 대표 사업장 무대를 완주해 **비전("국민 모두가 평생 즐기는 K-스포츠 허브")**에 도달합니다.

## ▶ 실행 방법

빌드 도구가 필요 없습니다. 정적 파일이므로 아래 중 한 가지로 실행하세요.

```bash
# 1) 가장 간단 — 로컬 서버 (이미지/오디오 로딩 권장)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 직접 열어도 동작합니다.
(GitHub Pages·사내 웹서버 등 정적 호스팅에 그대로 배포 가능)

## 🎮 조작

| 환경 | 조작 |
|------|------|
| PC | `Space` 또는 `↑` = 점프 |
| 모바일 | 화면 탭 = 점프 |

- 장애물(**안일·무기력·비효율·은폐**)을 뛰어넘으세요. = 극복 대상
- 코인(**존중·조화·정정당당**)을 모으면 보너스 점수(+50). = 경영방침
- 점수가 차면 다음 무대로 자동 전환됩니다.

## 🏟 무대 구성

| 무대 | 사업장 | 동작 | 전환 점수 |
|------|--------|------|-----------|
| STAGE 1 | 올림픽공원 | 달리기 | 0 → 500 |
| STAGE 2 | 스피돔(경륜) | 자전거 | 500 → 1,200 |
| STAGE 3 | 미사 경정장(경정) | 모터보트 | 1,200 → 2,000 → 클리어 |

## 🗂 프로젝트 구조

```
KSPORUN_GAME/
├─ index.html          # 진입점 (UI 오버레이 포함)
├─ css/style.css       # 스타일 (CI 컬러 변수)
├─ js/
│  ├─ config.js        # ★ 모든 튜닝 상수 (색상·속도·점수·키워드·전환 임계값)
│  ├─ game.js          # 게임 루프 & 상태머신 (타이틀/전환/플레이/오버/클리어)
│  ├─ player.js        # 백호돌이 (무대별 동작·점프 물리·보트 합성)
│  ├─ obstacles.js     # 장애물(극복 키워드) + 코인(경영방침)
│  ├─ stages.js        # 무대별 패럴랙스 배경 렌더링
│  ├─ audio.js         # 효과음/BGM (Web Audio 합성) + 음소거
│  ├─ share.js         # 결과 이미지 캡처 + 링크 공유 (백엔드 없음)
│  ├─ ui.js            # DOM 오버레이 화면 관리
│  └─ leaderboard.js   # (선택·기본 비활성) 통합 랭킹 모듈
├─ assets/
│  ├─ images/          # 전처리 완료된 백호돌이 스프라이트 + manifest.json
│  └─ sounds/          # (선택) CC0 음원 배치 위치
├─ tools/
│  └─ prepare_assets.py # 원본 PNG → 투명 누끼·크롭·반전 전처리 스크립트
└─ docs/기획서_v3.md    # 게임 기획서
```

> 게임 밸런스(속도·점수·전환 기준·키워드·색상)는 **`js/config.js`** 한 곳만 수정하면 됩니다.

## 💾 점수 저장 · 공유 (백엔드 없음 / 0단계)

- **개인 최고점수**: 브라우저 `localStorage`에 저장 (기기/브라우저 한정, DB 불필요).
- **결과 공유**: 결과 카드를 이미지로 캡처해 저장/SNS 공유, 점수를 담은 URL 링크(`?score=`) 공유.
- **통합 랭킹**(선택): 필요 시 `js/leaderboard.js`의 `ENABLED = true` + 관리형 BaaS(Firebase/Supabase) 연동.
  본체 수정 없이 on/off 가능하도록 분리되어 있습니다.

## 🔊 사운드

- 현재 효과음(점프·충돌·코인·전환·클리어)과 BGM은 **Web Audio API로 합성**되어 있어 별도 음원 파일 없이 동작합니다.
- CC0(상업적 사용 가능) 음원으로 교체하려면 `assets/sounds/`에 파일을 넣고 `js/audio.js`에서 로드하세요.
  교체 시 출처·라이선스를 이 README에 명기합니다.

## 🖼 에셋 전처리

`assets/images/`의 스프라이트는 원본 PNG 11종을 전처리(투명 누끼·크롭·반전·리사이즈)한 결과물입니다.
재가공이 필요하면 `tools/prepare_assets.py`를 참고하세요 (Pillow flood-fill 누끼 방식).
파일별 역할 매핑은 `assets/images/manifest.json` 및 `ASSETS_README.md` 참고.
