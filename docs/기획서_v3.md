# 달려라 백호돌이 — 게임 제작 기획서 [확정본 v3]

> Claude Code에 전달하여 웹 게임을 구현하기 위한 기획서입니다.
> 크롬 공룡 게임(T-Rex Runner) 방식의 엔드리스 러너를 기반으로,
> 회사의 경영가치를 대내외에 알리는 홍보용 미니게임을 제작합니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 게임명 | **달려라 백호돌이** |
| 목적 | 회사 경영가치(미션·비전·핵심가치·경영방침)를 재미있게 체험·각인 |
| 활용처 | 사내 행사 부스, 워크숍, 외부 홍보 페이지, SNS 공유 |
| 플랫폼 | 웹 브라우저 (PC + 모바일), 설치 불필요, 단일 페이지 |
| 플레이 시간 | 1회 1~3분 (가볍게 즐기는 캐주얼 게임) |
| 핵심 컨셉 | 백호돌이가 "핵심가치에 반하는 키워드(장애물)"를 뛰어넘으며 3개 무대를 완주 |

### 게임에 담을 핵심 메시지
- **장애물 = 극복 대상**: 핵심가치의 반대 개념을 백호돌이가 뛰어넘는다 = "우리는 이런 것을 극복하고 가치를 지향한다".
- **3개 무대 = 회사 대표 사업장**: 올림픽공원 / 스피돔(경륜) / 미사리 경정장(경정).
- **완주 = 비전 달성**: 엔딩에서 "국민 모두가 평생 즐기는 K-스포츠 허브" 메시지 전달.

---

## 2. 경영가치 (게임 내 반영 대상)

- **미션**: 스포츠로 국민이 건강하고 행복한 삶을 누리는 데 이바지
- **비전**: 국민 모두가 평생 즐기는 K-스포츠 허브
- **핵심가치**: 탁월 · 열정 · 실용 · 투명
- **경영방침**: 존중 · 조화 · 정정당당

---

## 3. 게임플레이 기본 메커니즘 (크롬 공룡 게임 기반)

- **조작**: 원버튼.
  - PC: `Space` 또는 `↑` = 점프, `↓` = 숙이기(선택)
  - 모바일: 화면 탭 = 점프
- **진행**: 배경이 왼쪽으로 자동 스크롤(오토러너). 백호돌이는 제자리에서 점프로 회피.
- **속도**: 시간이 지날수록 점차 빨라짐(난이도 상승).
- **충돌**: 장애물에 부딪히면 게임 오버.
- **점수**: 거리(시간) 기준 자동 가산 + 수집 아이템 보너스. 화면 우상단 표시.
- **목표**: 점수를 채워 다음 무대로 진입 → 3개 무대 완주 시 클리어 엔딩.

> 핵심은 "단순·직관·중독성". 크롬 공룡 게임의 손맛을 유지하되, 무대·캐릭터·장애물만 교체합니다.

---

## 4. 무대(스테이지) 구성

3개 무대로 구성되며, 각 무대는 일정 점수 도달 시 자동 전환됩니다.

### 4-1. 1단계 — 올림픽공원 (달리기)
- **배경**: 올림픽공원(세계평화의문/잔디 언덕 실루엣). 하늘 → 조형물/나무 → 잔디 패럴랙스.
- **백호돌이 동작**: 측면 **달리기** (단일 스프라이트 + 위아래 바운스/스쿼시로 달리는 느낌).
- **장애물**: 지면 위 표지판/허들. 위로 점프해 회피.
- **속도감**: 보통 (입문, 난이도 낮음).

### 4-2. 2단계 — 스피돔 / 경륜경기장 (자전거)
- **배경**: 경륜 트랙(기울어진 뱅크), 관중석·트랙 라인 실루엣.
- **백호돌이 동작**: **자전거 주행** (측면 라이딩 스프라이트).
- **장애물**: 트랙 위 콘/배리어. 점프로 회피.
- **속도감**: 빠름.

### 4-3. 3단계 — 미사리 경정장 / 경정경기장 (모터보트)
- **배경**: 수면(물결 애니메이션), 부표·턴마크·심판탑 실루엣.
- **백호돌이 동작**: **모터보트 운전**. ※ 보트 포즈 에셋이 없으므로 캔버스로 보트를 그리고 그 위에 백호돌이(얼굴 아이콘/상체)를 합성.
- **장애물**: 물 위 부표/파도/부이. 점프(보트 점프)로 회피.
- **속도감**: 가장 빠름 (클라이맥스).

> **전환 연출**: 무대 전환 시 짧은 카드("STAGE 2 · 스피돔(경륜)" + 사업장 한 줄 소개)를 0.5~1초 노출.

## 5. 핵심가치 ↔ 장애물(극복 대상) 매핑

각 핵심가치에 반하는 부정 키워드를 장애물 라벨로 표기. 시작 화면에 "장애물은 우리가 **극복할 대상**입니다"를 명시해 메시지를 분명히 합니다.

| 핵심가치 | 장애물(극복 대상) | 비고 |
|----------|------------------|------|
| 탁월 | **안일** | |
| 열정 | **무기력** | |
| 실용 | **비효율** | |
| 투명 | **은폐** | |

- 장애물(표지판/콘/부표) 위에 해당 키워드 텍스트를 작게 표기.
- 무작위 등장, 무대가 진행될수록 빈도/조합 난이도 상승.

### 경영방침 = 수집 아이템 (포함 확정)
- 트랙 위에 **존중 · 조화 · 정정당당** 코인을 배치 → 점프로 획득 시 보너스 점수 + 획득 이펙트/효과음.
- 코인 베이스는 **백호돌이 얼굴 아이콘** 활용 또는 CI 3색(블루/스카이블루/오렌지) 토큰 + 방침 텍스트.
- "나쁜 것은 피하고, 좋은 가치는 모은다"는 직관적 메시지 강화.

## 6. 점수 · 난이도 · 무대 전환 규칙

- **점수**: 거리(시간) 기반 자동 증가(예: 10점/초) + 코인 보너스(예: 코인당 +50).
- **무대 전환 기준(예시, config에서 조정)**:
  - 1단계: 0 ~ 500점 → 2단계
  - 2단계: 500 ~ 1,200점 → 3단계
  - 3단계: 1,200 ~ 2,000점 → 클리어
- **난이도 곡선**: 무대 상승 시 ① 스크롤 속도 ↑ ② 장애물 간격 ↓ ③ 패턴 다양화.
- **목숨**: 기본 1목숨(충돌 시 게임 오버). (선택: 무대당 라이프 옵션)

## 7. 점수 저장 · 공유 (백엔드 전략)

> 복잡도를 낮게 유지하기 위해 **단계적 접근**. 0~1단계는 백엔드/DB가 전혀 필요 없습니다.

### 0단계 — 백엔드 없음 (기본 채택)
- **개인 최고점수**: 브라우저 `localStorage`에 저장(해당 기기/브라우저 한정). DB 불필요.
  - (주의) 이 저장은 Claude Code로 만든 **실제 배포 웹앱**에서 정상 동작합니다.
- **공유**: ① 결과 화면(점수·도달 무대·백호돌이)을 캔버스 이미지로 캡처 → 저장/SNS 공유,
  ② 점수를 URL 파라미터로 담아 "내 점수 깨봐!" 링크 공유.
- 운영 부담·비용·개인정보 이슈 = 0. 행사·홍보 수요 대부분 충족.

### 1단계 — 현장 키오스크 랭킹 (백엔드 없음)
- 부스의 특정 기기에서만 운영 시, 그 기기 `localStorage`에 점수가 누적 → "오늘의 TOP 10" 자동 구현.

### 2단계 — 통합 온라인 랭킹 (선택, 관리형 백엔드)
- 전 사용자 공통 실시간 랭킹이 필요할 때만 도입. 직접 서버 구축 X → **Firebase Firestore / Supabase** 등 관리형 BaaS(무료 요금제 + 클라이언트 코드 수십 줄).
- 고려사항: ① 클라이언트 게임 특성상 점수 위조가 쉬움 → 닉네임 + 최소 검증 ② 외부 공개 시 개인정보(닉네임 등) 최소 수집·안내 ③ 무료 한도 초과 시 비용.
- **구현 원칙**: 점수 제출/랭킹 조회를 별도 모듈(`leaderboard.js`)로 분리해, 본체 수정 없이 나중에 on/off 가능하게 설계.

## 8. 화면(UI) 구성

1. **시작 화면(Title)**: 게임명, 대표 백호돌이(정장/트렌치코트), 룰 1~2줄, "장애물은 극복 대상! 끝까지 달려 비전에 도달하세요" 안내, 음소거 토글.
2. **게임 화면(Play)**: 상단 점수/무대 표시(얼굴 아이콘), 패럴랙스 배경 + 백호돌이 + 장애물 + 코인.
3. **무대 전환 화면**: "STAGE 2 · 스피돔(경륜)" + 사업장 한 줄 소개(경륜 컷 활용).
4. **게임 오버 화면**: 최종 점수/도달 무대, 게임오버 백호돌이(갸루피스), 격려 문구, "다시 도전 / 점수 공유".
5. **클리어 화면(Ending)** ★메시지 핵심: 비전 문구 **"국민 모두가 평생 즐기는 K-스포츠 허브"** + 미션/핵심가치 요약, 축하 백호돌이(콩순이/훈이피스), "다시 하기 / 공유".

| `백호돌이_얼굴_아이콘.png` | 얼굴만 | UI 아이콘·점수·파비콘·**수집 코인 베이스** |

### ⚠️ 에셋 전처리(누끼) — 중요 기술 노트
- 제공 PNG는 모두 **투명 배경이 아님(RGB)**. 배경색은 대부분 **검정 `#000`**, `백호돌이_경륜_`만 **흰색 `#fff`**.
- 캐릭터가 **흰 몸통 + 검은 외곽선**이라, 단순 "검정/흰색 일괄 제거"를 하면 외곽선 또는 몸통이 같이 지워짐.
- → **가장자리에서 같은 색으로 연결된 배경 영역만 제거하는 플러드필(flood-fill) 방식**으로 누끼를 따야 함.
  - 권장: Python `Pillow` + flood fill(또는 `numpy` 마스크), 테두리 시드에서 배경색 허용오차 내 연결 픽셀만 투명화.
- 처리 순서: ① 플러드필 누끼 → ② 내용 경계로 크롭 → ③ 게임용 크기로 리사이즈 → ④ 측면 컷(골프/자전거_가방)은 **수평 반전**(진행 방향=우향).
- 3단계 보트: 전용 포즈 없음 → 캔버스로 모터보트를 그리고 그 위에 백호돌이를 합성. (추후 보트 일러스트 추가 시 교체)

## 10. 사운드 (포함 확정)

- **BGM**: 무대별 경쾌한 루프(또는 공통 1트랙). 시작 시 **음소거 토글** 제공.
- **효과음**: 점프 / 충돌(게임오버) / 코인 획득 / 무대 전환 / 클리어.
- 구현: Web Audio API 또는 `<audio>`. 모바일 자동재생 제한 고려 → 첫 탭(사용자 입력) 시 오디오 활성화.
- 라이선스: 보유 음원이 없으므로 **무료·상업적 사용 가능 음원(CC0 등)**으로 진행. 출처·라이선스는 README에 명기.

## 11. 기술 스택 · 실행 환경

- **권장 스택**: **순수 HTML + CSS + JavaScript (Canvas API)**, 빌드 도구 불필요 → `index.html` 실행만으로 동작.
- **반응형/입력**: 데스크톱(키보드) + 모바일(터치) 지원, 캔버스 리사이즈.
- **배포**: 정적 호스팅(사내 웹서버, GitHub Pages 등) 또는 단일 파일 공유.
- **브라우저**: 최신 Chrome/Edge/Safari.

```
bhd-runner/

├─ css/style.css
```
